## 🧠 About

This is my personal portfolio website — designed to look and feel like an **AI-powered interface**, not just a static page. It introduces me through an animated "system boot" terminal, showcases my projects, skills, and certifications, and lets visitors reach out directly, all wrapped in a dark, glowing, sci-fi aesthetic.

Built entirely with **plain HTML, CSS, and JavaScript** — no frameworks, no build tools. Just open `index.html` and it runs.

🔗 **Live:** [anshuraj1201.vercel.app](https://anshuraj1201.vercel.app/)

---

## ✨ Features

- 🌌 **AI boot-sequence terminal** — types out my profile details (name, role, focus, status) like a live system scan
- 🔵 **Interactive cursor-light** — a soft blue glow that tracks the mouse in real time
- 🪐 **Holographic photo frame** — rotating dashed rings around a profile photo, with a floating animated AI badge
- 📊 **Animated skill bars** — fill in smoothly as they scroll into view
- 🏆 **Certifications section** — clean cards for courses, badges, and achievements
- 💬 **Feedback / contact form** — Name, Email, and Message fields that open a pre-filled email — no backend required
- 📄 **Resume tools** — both a direct **Download** button and an in-page **Preview** modal for the PDF
- 🧩 **Live GitHub stats card** — auto-pulled from my GitHub profile
- 🔍 **SEO-ready** — meta description & Open Graph tags for clean link previews when shared
- 📱 **Fully responsive** — adapts across desktop, tablet, and mobile

## 🌐 Deployment

This site is deployed on **Vercel** with zero configuration:

1. Push this repository to GitHub
2. Import the repo into [Vercel](https://vercel.com/new)
3. Framework preset: **Other** (static HTML — no build step)
4. Deploy 🎉

Every push to `main` auto-redeploys the live site.

## 🖊️ Customization

All content lives in a single file — `index.html`:

- **Profile info** → edit the `<h1>`, hero paragraph, and the `#terminalBody` lines
- **Photo** → replace `Portfolio.jpg` with your own image (same filename, or update the `src`)
- **Resume** → replace `resume.pdf` with your own file (same filename, or update the `href`)
- **Skills** → update the `.skill-top` labels/percentages and matching `data-fill` values
- **Projects** → duplicate a `.project-card` block for each project
- **Colors** → all controlled from the `:root { }` CSS variables at the top of the `<style>` block
